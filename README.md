Мини канбан-доска

Кратко
Это маленькое веб-приложение в стиле упрощённого Trello. Есть три колонки (To Do, In Progress, Done), карточки задач, перетаскивание мышкой, боковая панель деталей задачи и контекстное меню с быстрыми действиями.

Структура репозитория
hw4_report/
 ├── app/
 │    └── README.md — описание технологий, запуск, скриншот
 ├── REPORT.md — текстовый отчёт по заданию
 ├── package.json, tsconfig.json и прочие служебные файлы
 └── src/ — исходный код React‑приложения

Запуск
1. Установить зависимости:
   npm install
2. Запустить dev‑сервер:
   npm start
3. Открыть в браузере:
   http://localhost:3000
