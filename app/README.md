Мини канбан-доска

Список технологий
- React
- TypeScript
- Zustand
- Create React App (react-scripts)
- CSS (кастомные стили без фреймворков)

Памятка по запуску
1. Установить зависимости:
   npm install
2. Запустить в режиме разработки:
   npm start
   Приложение откроется на http://localhost:3000
3. Собрать продакшн-версию:
   npm run build

Скриншот стартовой страницы
- Сохранить файл со скриншотом, например screenshot.png, рядом с этим README
- На скрине должна быть видна мини канбан-доска с тремя колонками To Do / In Progress / Done и несколькими задачами
